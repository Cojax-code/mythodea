Vague 1 - Premier combat et formation

----------------------------------------------------------

CONSEIL
Lire le rapport du dernier tour.

>>> COMMANDE

cat {game_path}/village/{joueur}/hotel_de_ville/rapport.txt

NOTE : Le rapport résume ce qui s'est passé pendant le tour terminé.

----------------------------------------------------------

CONSEIL
Regarder ce qu'il reste de votre général après le premier combat.

>>> COMMANDE

tree {game_path}/village/{joueur}/garnison/1/general1

NOTE : Comparer l'avant et l'après aide à comprendre les pertes.

----------------------------------------------------------

CONSEIL
Déplacer une unité d'un bloc vers un autre.

>>> COMMANDE

mv {game_path}/village/{joueur}/garnison/1/general1/arriere/archer1 {game_path}/village/{joueur}/garnison/1/general1/droite/

NOTE : mv déplace ici tout le dossier de l'unité : ses fichiers enfants, comme arc, suivent automatiquement sans option supplémentaire. Un bloc doit rester homogène ; mélanger plusieurs types peut le rendre invalide.

Dans un combat 1 contre 1, les deux généraux engagés opposent leurs quatre blocs : avant, droite, gauche et arrière. La composition de ces blocs détermine quelles unités participent aux différents échanges.

Le rapport permet de comparer les effectifs avant et après le combat. Un général qui perd toutes ses unités est détruit ; un survivant conserve ses pertes pour les tours suivants. Les formations deviennent donc importantes dès le premier affrontement.
