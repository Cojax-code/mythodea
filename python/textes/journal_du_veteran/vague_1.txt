Vague 1 - Lire rapidement un combat

----------------------------------------------------------

CONSEIL
Extraire du rapport les lignes utiles au bilan sans relire tout le fichier.

>>> COMMANDE VÉTÉRAN

grep -Ein 'perte|surviv|résultat|force' {game_path}/village/{joueur}/hotel_de_ville/rapport.txt

NOTE : -E autorise plusieurs motifs avec |, -i ignore la casse et -n affiche les numéros de ligne.

----------------------------------------------------------

CONSEIL
Afficher une portion du rapport autour d'une information trouvée.

>>> COMMANDE VÉTÉRAN

sed -n '1,80p' {game_path}/village/{joueur}/hotel_de_ville/rapport.txt

NOTE : sed -n permet de sélectionner une plage de lignes sans modifier le fichier.

----------------------------------------------------------

CONSEIL
Déplacer une unité complète entre deux blocs.

>>> COMMANDE VÉTÉRAN

mv {game_path}/village/{joueur}/garnison/1/general1/arriere/infanterie1 {game_path}/village/{joueur}/garnison/1/general1/droite/

NOTE : mv déplace le dossier entier : le fichier arc qu'il contient suit automatiquement.
