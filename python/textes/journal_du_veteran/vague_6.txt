Vague 6 - Crypte : récupérer et vérifier une recette

----------------------------------------------------------

CONSEIL
Télécharger une recette dans un dossier local explicite.

>>> COMMANDE VÉTÉRAN

mkdir -p ./recettes
scp {joueur}@Mythodea.local:{game_path}/village/{joueur}/crypte/grimoire/recette1.txt ./recettes/

NOTE : À exécuter sur votre PC. La destination explicite évite de perdre le fichier dans le mauvais répertoire local.

----------------------------------------------------------

CONSEIL
Calculer l'empreinte SHA-256 du fichier texte après téléchargement.

>>> COMMANDE VÉTÉRAN

sha256sum ./recettes/recette1.txt

NOTE : Une empreinte permet de vérifier qu'un fichier n'a pas été modifié entre deux copies.

----------------------------------------------------------

CONSEIL
Lire la recette page par page dans le terminal.

>>> COMMANDE VÉTÉRAN

less ./recettes/recette1.txt

NOTE : Utilisez les flèches pour parcourir le document, / pour chercher et q pour quitter.
